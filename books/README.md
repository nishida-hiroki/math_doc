# 読書データベース

読んだ本を記録するツール。ISBNバーコードをカメラでスキャンして書誌情報を自動取得できる。

## 起動方法

```
books/start.bat をダブルクリック
```

その後 Chrome または Edge で http://127.0.0.1:5001 を開く。

※ 初回は pip install が走るので少し時間がかかる。

## 使い方

### バーコードスキャンで追加（推奨）

1. 「バーコードスキャン」ボタンを押す
2. カメラの許可を求められたら「許可」
3. 本の裏のバーコード（ISBN）にカメラを向ける
4. タイトル・著者・表紙が自動入力される
5. タグ（例: `math, textbook`）を入力して「保存」

### 手動で追加

1. 「+ 追加」ボタンを押す
2. タイトル・著者・タグなどを入力して「保存」

### 検索・絞り込み

- 上部の検索欄にキーワードを入力するとタイトル・著者・ISBNで絞り込める
- タグのピルボタンをクリックするとタグで絞り込める

### 編集・削除

- 本のカードにある「編集」「削除」ボタンから操作

## データについて

- データは `books/books.json` にテキスト形式で保存される
- GitHubにコミットすれば読書履歴をバージョン管理できる
- AIに読ませることもできる（バイナリ不使用）

## 注意

- ISBNの自動検索は Open Library API を使用。インターネット接続が必要。
- 日本語の本は Open Library に登録されていないことがある。その場合は手動入力。
- バーコードスキャンは Chrome または Edge のカメラ機能を使う（Safari は非推奨）。
