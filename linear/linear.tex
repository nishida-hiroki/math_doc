\begin{definition}
    体$F$（$F$は主に$\mathbb{R}$か$\mathbb{C}$）
    上のベクトル空間$V$が\textbf{計量ベクトル空間}であるとは
    写像$V\times V\rightarrow F,\,(a,b)\mapsto a\cdot b$
    が存在して
    次の四つの公理を満たすことである．
    \begin{enumerate}
        \item $(a_1+a_2)\cdot b=a_1\cdot b+a_2\cdot b$
        \item $(ca)\cdot b=c(a\cdot b)$ただし$c\in F$
        \item $a\cdot b=\overline{b\cdot a}$（複素共役）
        \item $a\cdot a \geq 0$
    \end{enumerate}
\end{definition}
公理３より$a\cdot a=\overline{a\cdot a}$であることからこれは実数である．
